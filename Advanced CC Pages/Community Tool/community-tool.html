IV. Community Tool

Build a community-facing digital tool and present it as part of your Advanced CC portfolio.

Phantopteryx Toolbox by Oneiron · old version — A lightweight local-browser toolbox that tested the first relationship between image editing, optional local Python AI services, and divination interfaces such as I Ching and Zi Wei Dou Shu.

This project became the foundation for the later Digital Divination / Phantopteryx Toolbox rebuild. The old version is useful as a community-tool prototype: it shows the early navigation, the local-first structure, and the idea of keeping browser tools and optional server tools separate.
