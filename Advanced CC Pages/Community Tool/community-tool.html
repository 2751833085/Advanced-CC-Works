Phantopteryx Toolbox by Oneiron · v0.1.0 — A lightweight toolbox for local browsers: image editing, optional local Python AI services (outpainting, background removal, LaMa, and related flows), and frontend shells for divination methods such as I Ching and Zi Wei Dou Shu.

Image Editor and Divination run entirely in the browser; AI-related features are invoked over local HTTP only when services/ai-server is running, with no model weights bundled in the repo. The Info panel lists open-source components and license notes.
