Image Editor Divination

Phantopteryx Toolbox

by Oneiron · v0.1.0
A minimal local toolkit: image editor + optional Python AI server + divination shell.

Open source · 图像 / AI 服务（本地）
  • Stable Diffusion inpainting — Hugging Face Diffusers + PyTorch. Expand (mode=ai) defaults to SDXL diffusers/stable-diffusion-xl-1.0-inpainting-0.1 or SD1.5 runwayml/stable-diffusion-inpainting (see EXPAND_SD_* in server README).
  • LaMa — large-mask inpainting for fill / remove-object (SAIC-MOD LaMa weights via simple-lama-inpainting); OpenCV Telea fallback when configured.
  • OpenCV — padding, mask ops, edge preview paths.
  • FastAPI — HTTP API for services/ai-server.
Open source · 占卜页（浏览器）
  • lunar-javascript — Gregorian ↔ lunar (npm).
  • iztro — Zi Wei chart helpers (npm).
  • I Ching text — Wilhelm-style hexagram fields from adamblvck/iching-wilhelm-dataset (see app README for license).
Editor client（无内置权重）

Image Editor UI is plain HTML/CSS/JS. AI features call your local server only when it is running.
